# Archived — do not run

These Node scripts were used during one-off refactors. They **overwrite** marketing files (`Landing.tsx`, `Navbar.tsx`, heroes) and have caused the public website to break or change unexpectedly.

**Do not run or restore them to `scripts/`.** Edit marketing pages in the IDE only.

If you need to change the homepage hero height, edit `.marketing-landing-hero` in `src/index.css` (see `docs/MARKETING_WEBSITE_LOCK.md`).
